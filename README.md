## Get it running

1. Unpack with the other files left beside each other.
2. Use `setup` from the shared folder.

---

## About

The archive is a plain zip. No installer runs behind it.

Start from an unpacked zip by running the file named `setup`. Later on, download the new archive and start it the same way.

---

## Small changes

- Any build after this one arrives as another archive.
- Extract the zip file and run `setup` to start the program
- This build is ready to run without any compilation or source tree access.
  - An issue about a start that failed should state the Windows version and the step that stopped.

---

## Key features

In short:

Delete that folder and the program goes with it. No Microsoft account is required at any point. Store the folder on a USB stick where writing is allowed. You do not need to compile anything to use the published build. No scheduled task is added by extraction or by the first launch. Settings live beside `setup` in the same folder. The extracted folder can be renamed after extraction. The program is provided as a single zip archive.
